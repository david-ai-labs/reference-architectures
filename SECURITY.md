# Security Policy

Security is a core engineering consideration
for DAVID AI Labs.

## Reporting Vulnerabilities

Do not disclose security vulnerabilities
through public GitHub issues.

Use GitHub Private Vulnerability Reporting
if enabled for this repository.

Otherwise, contact DAVID AI through:

https://david.partners

## Scope

Public repositories may contain experimental
software and reference implementations.

Unless explicitly documented otherwise,
projects should not be assumed production-ready.

Never include confidential client information,
API keys, credentials, or private datasets.
