# Contributing to DAVID AI Labs

Thank you for your interest in contributing.

## Contribution Guidelines

1. Open an issue before proposing significant changes.
2. Explain the problem and proposed approach.
3. Keep changes focused and well documented.
4. Include tests for executable functionality.
5. Document relevant assumptions and limitations.
6. Never commit secrets, credentials, or client data.

## Pull Requests

Each pull request should include:

- Description of the problem
- Summary of implementation
- Testing performed
- Known limitations
- Relevant documentation updates

## Code Review

Maintainers review contributions for correctness,
security, maintainability, and project scope.

Contributions are subject to maintainer approval.
